# Week 5 Assignment: Password Generator & Modules

This repository showcases the implementation of Python built-in modules alongside the creation and cross-importation of custom modules.

## Files Created
* **password_generator.py**: Leverages the built-in `random` and `string` libraries to construct highly random alphanumeric password values.
* **helpers.py**: Acts as a custom utility function module handling ceiling mathematical soundings and greeting strings.
* **main.py**: The entry script that imports the helper library module to test operational logic scopes.

## Reflection
The hardest function to write was `tables_needed` within `helpers.py`. While simple division yields floating values, correctly utilizing the `math.ceil()` library extension to handle complete integers reminded me how strict logic rules translate layout expectations to technical operations.
